# 河图剧本杀工坊

通过河图稳定CLI/MCP发现当前启用包、活动摘要、真实Schema与包内方法。读取确切作品、固定来源、已有工程和旧试玩；包由河图热插拔，不另注册Codex插件或MCP服务。

默认流程：整案目标与案情 → 人物动机与分幕正文 → 明确知情事实与证据推导 → 搜证交换投票轮次 → 角色本和主持本审阅 → 固定版本测本 → 具体卡点意见 → 局部返工和新版复测。

旧工程先明确enable_depth或准备完整可选扩展，普通读取不迁移；旧sessions与快照保持，完整机制测本使用depth.test_runs。正文与推导先读basis再准备完整写入，改依据后明确复核，不自动重签。

[专业流程](references/workflows.md)提供兼容、机制、测本和接续方法；[操作地图](references/operations.md)由正式清单生成，执行参数以当前发现为准。

保存使用CAS和原operation_key。未知先get_operation，冲突保留输入；每阶段回读固定修订。角色投影按实际发放和幕次过滤，但看过主持资料的同一Codex对话不构成隔离玩家或真人体验证明。模拟明确agent_simulated，线索发放只记录，不发送消息。

采纳、定稿、内容外发与费用按作者确切决定分别处理。
