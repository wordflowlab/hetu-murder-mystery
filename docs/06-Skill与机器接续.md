# Skill与机器接续

## 接入方式

本包Skills随河图插件注册，外部Codex经同一稳定CLI/MCP即时发现`skills.read`，读取`hetu-murder-mystery`入口及按需参考。不向Codex安装同名插件，不增加永久客户端工具名，安装生命周期与作品管理连接分开。

## 默认旅程

读取固定原著与人物→建立主持和角色资料→安排分幕及线索接收者→导出分角色资料→固定工程开始试玩→记录发放、推测与复盘→交给宿主规划或候选→新版重新试玩。

方法入口为[SKILL](../skills/hetu-murder-mystery/SKILL.md)，[操作地图](../skills/hetu-murder-mystery/references/operations.md)随清单生成，[流程](../skills/hetu-murder-mystery/references/workflows.md)描述专业决策。

## 有界发现与内容

先发现当前包摘要与专业Schema，再精确读取必要宿主动作。不全量加载所有插件方法，不用压缩摘要冒充已读原文。大成果使用summary与固定分块完整核验；只读投影不改变写入原输入。

## 恢复与用户决定

未知写入先查原键；同输入明确未落盘才恢复，不换键重复写入。CAS冲突保留输入。Agent执行准备与确定性事务，作者保留采纳、定稿、费用和外发决定。本包是创作与线下试玩记录工具，不是线上游戏服务器或独立权限系统。玩家投影只返回选定角色可见资料；作者仍可使用主持视角。模拟试玩明确agent_simulated，不冒充真人反馈。发放只记录，不发送消息。正式人物、正文采纳和定稿归宿主；泄漏结构检查不判断文本自身是否暗示真相。
